# Прогнозирование эффективности химических соединений

Этот проект направлен на построение и сравнение моделей машинного обучения для оценки биологической активности химических соединений. Исследование включает как регрессионные, так и классификационные задачи.

## Структура проекта

### Ноутбуки

#### Анализ данных
- `eda.ipynb` — анализ представленных данных (EDA: Exploratory Data Analysis)

#### Регрессия
- `IC50Reg_f.ipynb` — прогноз значения **IC50** (концентрации, подавляющей 50% активности)
- `CC50Reg_f.ipynb` — прогноз значения **CC50** (концентрации, вызывающей 50% токсичности)
- `SIReg_f.ipynb` — прогноз **SI** (индекса селективности, вычисляемого как CC50 / IC50)

#### Классификация
- `IC50Class_f.ipynb` — определение, превышает ли **IC50** медиану выборки
- `СC50Class_f.ipynb` — определение, превышает ли **CC50** медиану выборки
- `SIClass_f.ipynb` — определение, превышает ли **SI** медиану выборки
- `SIClass8_f.ipynb` — определение, превышает ли **SI** значение **8**, важное с практической точки зрения

### Отчёты
- `report.docx` — текстовый аналитический отчёт в формате Microsoft Word
- `report.pdf` — тот же отчёт в формате PDF

## Используемые технологии
- Python (pandas, scikit-learn, XGBoost, CatBoost, LightGBM)
- Jupyter Notebook
- matplotlib, seaborn для визуализации

## Цель
Помочь в выборе наиболее эффективных комбинаций параметров и моделей для оценки потенциальных лекарственных соединений. Проект может служить основой для автоматизации оценки in silico до начала in vitro тестов.
